# Segurança

Não reporte vulnerabilidades publicamente. Abra um Security Advisory privado no GitHub do projeto quando o repositório estiver publicado, incluindo passos de reprodução e impacto. Não envie chaves Pix reais, senhas ou backups contendo dados pessoais.

A versão inicial não oferece backup criptografado e ainda não deve ser considerada pronta para distribuição de produção.
