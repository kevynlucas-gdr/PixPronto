# Contribuindo

1. Abra uma issue descrevendo o problema ou proposta.
2. Mantenha regras de BR Code isoladas em `pix/` e cubra-as com testes.
3. Não inclua dados pessoais, chaves Pix reais ou segredos em commits e logs.
4. Execute `./gradlew testDebugUnitTest lintDebug assembleDebug` antes de abrir PR.
5. Descreva mudanças de comportamento e limitações no pull request.

Toda contribuição distribuída neste repositório deve ser compatível com GNU GPL-3.0-or-later.
