
# UI — User Interface

Esta pasta contém a interface gráfica do PixPronto,
desenvolvida com Kotlin, Jetpack Compose e Material 3.

Organização prevista:
- Screens: telas do aplicativo.
- Components: componentes reutilizáveis.
- Theme: cores, tipografia e estilos.
- Navigation: navegação entre telas.

O código-fonte será adicionado nesta pasta.
